# AI Studio redirect

LinkedIn Featured already uses `https://fabricio-rodriguez-portfolio.ai.studio/`.
Keep that URL. Do not 301 it.

## Publish in Google AI Studio

1. Open the existing portfolio app in [Google AI Studio](https://aistudio.google.com) Build mode.
2. Replace `index.html` with this file. Do not unpublish or delete the app, or the `.ai.studio` name can be released.
3. Publish again with the same custom URL: `fabricio-rodriguez-portfolio`.

People land on Cloudflare Pages. LinkedIn still scrapes `.ai.studio`.
